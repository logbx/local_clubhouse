# Project Rules & Conventions

## Backend (NestJS)
- Use TypeScript for all code.
- Follow NestJS module/controller/service structure.
- Use environment variables for secrets and config.
- Write unit and e2e tests for all endpoints.
- Use Prettier and ESLint for code style.
- Document all public APIs with Swagger.

## Frontend (React + Vite)
- Use TypeScript for all components and hooks.
- Use functional components and React hooks.
- Use Tailwind CSS for styling.
- Use React Query for data fetching.
- Keep all state in context or hooks, avoid Redux unless necessary.
- Write tests for all components and hooks.
- Use ESLint and Prettier for code style.

## General
- All code must be reviewed before merging.
- Use descriptive commit messages.
- Keep documentation up to date.
